# Lab 6 - Responsive Movie Genre Browsing Screen

Single-file Flutter demo in `lib/main.dart`, suitable for DartPad.

Features:

- `MediaQuery` and `LayoutBuilder` breakpoints.
- Responsive heading, search bar, genre `FilterChip`s with `Wrap`.
- Sort dropdown: A-Z, Z-A, Year, Rating.
- Phone layout: one-column `ListView`.
- Wide layout >= 800px: two-column `GridView`.
- Bonus: selected genre badge, rating text, clear filters button.

Run:

```powershell
cd D:\PRM_LAB\thuchanh_PRM\lab6_responsive_genre_browsing
flutter run
```
