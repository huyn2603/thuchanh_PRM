# Lab 8B - Practical REST API Weather Companion

Chosen scenario: Weather Companion App.

Purpose: help users decide whether to bring an umbrella or go outside.

Features:

- Real REST API integration with Open-Meteo geocoding + forecast APIs.
- `WeatherReport` model and `OpenMeteoWeatherService` service layer.
- `FutureBuilder` loading/error/data states.
- City search form.
- Decision text: umbrella / too hot / nice for walk.
- Retry action for errors.

Run:

```powershell
cd D:\PRM_LAB\thuchanh_PRM\lab8b_practical_rest_app
flutter pub get
flutter run
```
