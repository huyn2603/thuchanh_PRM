# Lab10_4_FirebaseGoogleSignIn

This project contains the Firebase Auth + Google Sign-In flow.

Before running real sign-in:

1. Create a Firebase project.
2. Add Android app package from this project.
3. Add SHA-1/SHA-256 keys.
4. Enable Google provider in Firebase Authentication.
5. Replace `FirebaseBootstrap.demoOptions` in `lib/main.dart` with real Firebase options.

Run:

```powershell
flutter pub get
flutter run
```
