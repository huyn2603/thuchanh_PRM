# Lab 7 - Signup Form with Validation and Good UX

Single-file Flutter demo in `lib/main.dart`, suitable for DartPad.

Features:

- `Form`, `TextFormField`, `GlobalKey<FormState>`.
- Required, email, password strength and confirm-password validators.
- `AutovalidateMode.onUserInteraction`.
- `FocusNode`, keyboard next/done flow, tap-outside keyboard dismiss.
- Terms checkbox, show/hide password, password strength indicator.
- Async fake email availability check: emails starting with `taken` are rejected.

Run:

```powershell
cd D:\PRM_LAB\thuchanh_PRM\lab7_signup_validation_ux
flutter run
```
