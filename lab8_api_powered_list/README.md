# Lab 8 - API-powered List Screen

Features:

- Real GET request to `https://jsonplaceholder.typicode.com/posts`.
- `Post` model with `factory Post.fromJson`.
- `HttpPostsApiService` service layer.
- `FutureBuilder`, loading state, error state, retry.
- `ListView.builder` with cards.
- Optional POST bottom sheet.
