# Lab 9 - Working With Local JSON Storage

Features:

- Lab 9.1: load `assets/data/movies.json` with `rootBundle.loadString`.
- Lab 9.2: read/write JSON in application documents directory.
- Lab 9.3: local JSON CRUD database with add, edit, delete, search.
- Uses `dart:convert`, `File`, `path_provider`, `ListView.builder`, `FloatingActionButton`.
- Auto-saves JSON after each CRUD action.

Run:

```powershell
cd D:\PRM_LAB\thuchanh_PRM\lab9_local_json_storage
flutter pub get
flutter run
```
